# Studying Tool

A digital desk clock for studying, with an optional countdown timer.

Made with AI — but still deterministic.

## What it does

- Big live clock in 12-hour AM/PM format — readable from across a desk
- Countdown timer: presets (15/30/45/60/90 min) or a custom duration
- A short beep and a visual flash when the timer ends
- No pomodoro, no streaks, no tasks, no analytics — just a clock

## Run it

Open `index.html` in any browser. Nothing to install, works offline.

The clock is the whole screen by default. Start a timer only when you want one.

## Theme

Dark by default. Five themes (Dark, Amber, Midnight, Forest, Slate) via the
swatches in the top-right corner. Your choice is remembered.
